How practice sets thresholds

Red markers show trigger values; dashed markers pin the practice peaks. Use Live view and have the user sip and puff firmly a few times. Their measured maximum stays on the gauge, and Suggest thresholds turns it into trigger values at 65% of each peak: a deliberate hold crosses them, while breathing noise should not.

When to use the hard band

For users who cannot hold a steady sip or puff for 1–3 seconds: a firm, brief sip or puff past the hard threshold fires its action the moment it is released — no hold length needed. The hard thresholds must stay at least 1 hPa above the regular ones, so a light sip or puff still uses the normal actions. Hard band settings need firmware 4.7.0+.

How to practice hold timing

The timeline is to scale: green = short, yellow = long, red = very-long — the same colors the small light next to the USB-C port shows while you hold. Watch holds streams real sips and puffs: a live bar sweeps the timeline as the device measures each hold, filling one zone per window.

Pairing instructions

1. Click Switch to Bluetooth. The device saves the setting, restarts, and begins advertising.

2. On your computer, open Bluetooth settings and look for the device name shown above.

3. Select it to pair. The LipSync appears as a mouse (HID).

4. To return to USB mode, reconnect via USB, open this panel, and select a USB mode from the operating mode dropdown in Overview & modes.

    Fix a problem

    Choose what is happening. Each path gives a short first check and opens the control or test that can help.

    Not sure where to begin?

    Run a health check, or create one report with device details and the session log.

    Cannot connect

    Use a USB data cable connected directly to the computer. Close serial-monitor apps, reconnect the cable, wait 10 seconds, then try again in Chrome, Edge, or Opera.

    Pointer is difficult to control

    Adjust speed before acceleration. If movement is uneven, inspect the live joystick view before recalibrating.

    Sip or puff is missed

    Practice with Live view first. Compare the measured peaks with the thresholds, then adjust sensitivity or hold timing one step at a time.

    Accidental inputs occur

    Add one safeguard at a time. You can freeze the pointer during mouthpiece input, lock the mode, or disable an input method.

    External switch is not working

    Test whether the press reaches the LipSync. If it does, review the action assigned to that jack and hold length.

    Bluetooth will not connect

    Keep USB connected, confirm Bluetooth Mouse mode and the advertised device name, then pair from the computer's Bluetooth settings after the restart finishes.

    Update was interrupted

    Replug the LipSync. If it only appears as an update loader, use the recovery action in Updates. The recovery loader remains intact and the settings backup can be restored.

    Still need help?

    Create a support report after reproducing the problem. Device identifiers are removed before the report is downloaded or shared.
